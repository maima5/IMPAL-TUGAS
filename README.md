## 📄 Deskripsi Isi Repository

### 1. README.md
Dokumen utama yang menjelaskan tujuan repository, identitas kelompok, struktur folder, serta daftar dokumentasi dan tugas yang tersedia.

### 2. SKPL — Spesifikasi Kebutuhan Perangkat Lunak
Dokumen yang menjelaskan kebutuhan perangkat lunak S-TIDY, meliputi gambaran sistem, kebutuhan fungsional, kebutuhan nonfungsional, serta kebutuhan pengguna dan sistem.

### 3. DPPL — Deskripsi Perancangan Perangkat Lunak
Dokumen yang menjelaskan rancangan sistem S-TIDY sebagai acuan implementasi, termasuk arsitektur, komponen, struktur data, dan rancangan perangkat lunak sesuai isi dokumen.


## 🗂️ Panduan Pengelolaan Tugas

Agar repository tetap rapi dan mudah digunakan, setiap anggota kelompok diharapkan mengikuti ketentuan berikut:

1. Simpan setiap tugas sesuai minggu perkuliahan atau topik pembahasannya.
2. Gunakan nama file yang jelas dan konsisten, misalnya `TUGAS_WEEK_04_S-TIDY.pdf`.
3. Sertakan file pendukung yang diperlukan untuk memahami hasil pengerjaan tugas.
4. Perbarui repository ketika terdapat tugas baru atau revisi dokumen.
5. Hindari menyimpan file duplikat, file sementara, atau file yang tidak berkaitan dengan perkuliahan.
6. Pastikan dokumen yang diunggah merupakan versi final atau versi revisi yang memang perlu dikumpulkan.

## 🎯 Tujuan Repository

- Mengarsipkan seluruh tugas mingguan kelompok secara terstruktur.
- Memudahkan anggota kelompok mengakses dan meninjau kembali hasil pengerjaan tugas.
- Mendokumentasikan perkembangan tugas akademik yang berkaitan dengan proyek S-TIDY.
- Menyimpan dokumen SKPL, DPPL, dan file pendukung lainnya dalam satu tempat.
- Mempermudah kolaborasi serta memastikan dokumentasi tugas dapat ditelusuri berdasarkan minggu perkuliahan.
